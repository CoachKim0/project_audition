# NetTest.cs 사용 매뉴얼

## 개요

NetTest.cs는 Unity OnGUI를 사용하여 NetworkManager를 통한 회원가입/로그인 패킷 처리를 테스트하는 도구입니다. UGUI 컴포넌트를 생성할 필요 없이 코드만으로 빠르게 네트워크 인증 기능을 테스트할 수 있습니다.

## 설치 및 설정

### 1. 스크립트 설정

1. Unity 씬에 빈 GameObject 생성
2. GameObject에 `NetTest.cs` 스크립트 추가
3. Inspector에서 기본 설정 확인:
   - Server Address: `127.0.0.1` (로컬 테스트용)
   - Server Port: `5554` (gRPC 포트)

### 2. 서버 준비

테스트 전에 반드시 서버를 실행해야 합니다:

```bash
cd Server/Server_Study/Server
dotnet run
```

서버가 정상 실행되면 다음 포트들이 활성화됩니다:
- TCP 포트: `7777`
- gRPC 포트: `5554`

### 3. NetworkManager 설정 확인

`Resources` 폴더에 `NetworkConfig` ScriptableObject가 설정되어 있는지 확인:
- defaultTransportType: `gRPC`
- serverAddress: `localhost` 또는 `127.0.0.1`
- serverPort: `5554`
- enableDebugLog: `true`

## UI 구성 및 기능

### 📡 서버 연결 섹션

#### 연결 설정
- **주소**: 서버 IP 주소 (기본값: `127.0.0.1`)
- **포트**: 서버 포트 번호 (기본값: `5554`)

#### 연결 버튼
- **🔌 연결**: 서버에 연결 시도
- **🔌 연결해제**: 서버 연결 해제

#### 상태 표시
- **연결 상태**: ✅ 연결됨 / ❌ 연결 안됨
- **인증 상태**: ✅ 인증됨 / ❌ 인증 안됨

### 👤 인증 정보 섹션

테스트할 사용자 정보를 입력합니다:

- **사용자명**: 로그인/회원가입에 사용할 ID
- **비밀번호**: 암호 (마스킹 처리됨)
- **이메일**: 회원가입 시 사용할 이메일
- **닉네임**: 사용자 닉네임

#### 기본 테스트 계정

서버에 미리 등록된 테스트 계정들:

| 사용자명 | 비밀번호 | 용도 |
|---------|----------|------|
| `testuser` | `password123` | 로그인 테스트용 |
| `admin` | `admin123` | 관리자 테스트용 |

### 🔐 인증 작업 섹션

#### 메인 기능 버튼
- **📝 회원가입**: 새로운 계정 생성
- **🔑 로그인**: 기존 계정으로 인증
- **🚪 로그아웃**: 현재 세션 종료

#### 유틸리티 버튼
- **🧪 빠른 테스트**: 자동화된 테스트 실행
- **📋 연결 정보**: 현재 네트워크 상태 표시
- **🗑️ 로그 지우기**: 응답 로그 초기화

### 📊 상태 & 응답 섹션

- **현재 상태**: 실시간 작업 상태 표시
- **마지막 응답**: 서버로부터 받은 응답 메시지 (스크롤 가능)

## 테스트 시나리오

### 기본 테스트 순서

#### 1. 서버 연결 테스트
1. 서버가 실행 중인지 확인
2. 주소/포트 설정 확인
3. **🔌 연결** 버튼 클릭
4. 연결 상태가 "✅ 연결됨"으로 변경되는지 확인

#### 2. 회원가입 테스트
1. 서버 연결 상태 확인
2. 새로운 사용자 정보 입력:
   ```
   사용자명: newuser123
   비밀번호: newpass123
   이메일: newuser@test.com
   닉네임: 새사용자
   ```
3. **📝 회원가입** 버튼 클릭
4. 응답 로그에서 결과 확인

#### 3. 로그인 테스트
1. 기존 계정 정보 입력:
   ```
   사용자명: testuser
   비밀번호: password123
   ```
2. **🔑 로그인** 버튼 클릭
3. 인증 상태가 "✅ 인증됨"으로 변경되는지 확인
4. 토큰이 수신되는지 로그 확인

#### 4. 로그아웃 테스트
1. 로그인된 상태에서 **🚪 로그아웃** 버튼 클릭
2. 인증 상태가 "❌ 인증 안됨"으로 변경되는지 확인

### 고급 테스트

#### 빠른 테스트 (🧪 빠른 테스트)
자동으로 다음 순서를 실행합니다:
1. 서버 연결 (연결되지 않은 경우)
2. 현재 입력된 정보로 회원가입 시도
3. 동일 정보로 로그인 시도

#### 실패 케이스 테스트

1. **잘못된 비밀번호 로그인**
   ```
   사용자명: testuser
   비밀번호: wrongpassword
   ```

2. **존재하지 않는 사용자 로그인**
   ```
   사용자명: nonexistent
   비밀번호: password123
   ```

3. **짧은 비밀번호 회원가입**
   ```
   사용자명: shortpass
   비밀번호: 123
   ```

4. **중복 가입 시도**
   ```
   사용자명: testuser (이미 존재하는 사용자)
   비밀번호: password123
   ```

## 결과 코드 참조

| 코드 | 의미 | 설명 |
|------|------|------|
| `0` | Success | 성공 |
| `1` | Fail | 일반적인 실패 |
| `2` | AuthenticationFailed | 인증 실패 (잘못된 사용자명/비밀번호) |

## 문제 해결

### 연결 실패 시
1. **서버 실행 상태 확인**
   ```bash
   # 서버 프로세스 확인
   netstat -an | findstr :5554
   ```

2. **방화벽 설정 확인**
   - Windows Defender 방화벽에서 포트 5554 허용

3. **주소/포트 설정 확인**
   - 로컬 테스트: `127.0.0.1:5554`
   - 원격 서버: 실제 서버 IP와 포트

### 인증 실패 시
1. **서버 로그 확인**
   - 서버 콘솔에서 오류 메시지 확인

2. **메시지 형식 확인**
   - AuthMessage 필드가 올바르게 설정되었는지 확인

3. **PlatformType 설정**
   - 로그인: `PlatformType = 1`
   - 회원가입: `PlatformType = 2`

### NetworkManager 초기화 오류
1. **SingletonBase 확인**
   - 씬에 NetworkManager 인스턴스가 있는지 확인

2. **NetworkConfig 설정**
   - `Resources/NetworkConfig.asset` 파일 존재 확인

## 개발자 정보

### 주요 이벤트 핸들러

- `OnConnectionChanged`: 연결 상태 변경 시 호출
- `OnAuthenticationChanged`: 인증 상태 변경 시 호출
- `OnMessageReceived`: 서버 메시지 수신 시 호출
- `OnError`: 네트워크 오류 발생 시 호출

### 사용된 패키지

- `Cysharp.Threading.Tasks`: 비동기 작업 처리
- `Newtonsoft.Json`: JSON 직렬화
- `NetworkManager.Core`: 네트워크 관리
- `NetworkManager.Messages`: 메시지 타입 정의

### 확장 가능한 기능

1. **추가 인증 타입**
   - OAuth, SNS 로그인 등

2. **메시지 타입 확장**
   - 채팅, 게임 데이터 등

3. **UI 개선**
   - 더 세련된 OnGUI 스타일링

## 주의사항

1. **OnGUI 성능**: OnGUI는 매 프레임 호출되므로 복잡한 로직은 피해야 합니다
2. **비동기 처리**: `UniTask`를 사용하여 UI 블록킹을 방지합니다
3. **메모리 관리**: 로그가 너무 길어지지 않도록 자동 정리됩니다
4. **스레드 안전성**: 메인 스레드에서만 UI 업데이트가 이루어집니다

이 매뉴얼을 통해 NetTest.cs를 활용하여 효율적으로 네트워크 인증 기능을 테스트할 수 있습니다.
